# VantanGP26_10 — 後期サンプル「3D探索アドベンチャー」【汚い版】

> **このブランチ（`lesson12-messy`）は第12回「コードの整理」用の "汚い版" です。**
> 完成形（`main`）と**同じ遊び心地**のゲームを、`Assets/Scripts/GameAllInOne.cs` **たった 1 つのスクリプト**で動かしています。
> プレイヤー・敵・弾・アイテム・鍵・扉・宝箱・スイッチ・チェックポイント・UI・セーブ・カメラが全部この 1 ファイルの中です。
> `kind` という文字列で「自分は何者か」を切り替え、変数はすべて `public`、設定値はコードに直書き、
> セーブのキーも文字列をあちこちに直書き……という状態になっています。
>
> **課題：このコードを「読める形」に整理してください。** 整理した結果の一例が `main` ブランチです（`git checkout main`）。

バンタン ゲームプログラマ26 1年生 **後期（第14〜25回）** の授業で分解して学ぶための完成サンプルです。
テーマは「C# の設計を深掘りする＝**きれいに作る**」。このブランチはその "きれいにする前" を体験するためのものです。

## 1. 動作環境

| 項目 | 内容 |
|------|------|
| Unity | **6000.3.x（Unity 6.3）**。6000.0 では開けません |
| レンダーパイプライン | **URP（Universal Render Pipeline 17.x）**。URP アセットは `Assets/Settings/` に同梱 |
| 入力 | 旧 Input Manager（`Input.GetAxis` / `Input.GetKeyDown`） |
| UI 文字 | TextMeshPro（UI の文字は英数字のみ） |
| 追加パッケージ | URP のみ |

## 2. 開き方

```bash
git clone -b lesson12-messy https://github.com/tanufuku/GP26_Oct.git GP26_Oct_messy
```

すでに `main` を clone している人は、そのフォルダで `git checkout lesson12-messy` でも切り替えられます
（Unity を開いたまま切り替えると再インポートが走ります。Unity を閉じてから切り替えるのが安全です）。

1. **Unity Hub で開く**（`Add` → `Add project from disk`）。Unity 6000.3 系を選ぶ。
2. `Assets/Scenes/Main.unity` を開いて **Play**。カプセル人間で遊べます。

このブランチには Asset Store 素材の読み込み・効果音・授業用の最小シーン・Prefab・ScriptableObject は**入っていません**
（全部 1 スクリプトに直書きされているため、差し替えの仕組みもありません）。

## 3. 操作方法

| キー | 操作 |
|------|------|
| W A S D / 矢印 | 移動 |
| Space | ジャンプ（タイトルではゲーム開始） |
| J / 左クリック | 攻撃（正面に弾を撃つ） |
| Esc | ポーズ／再開 |
| C（タイトル） | チェックポイントから続きを始める（セーブがあるとき） |
| R（ゲームオーバー） | チェックポイントからやり直す |

**ゲームの流れ**：エリアA（看板・スイッチで扉1を開ける）→ エリアB（巡回する敵・鍵・宝箱×2・鍵付きの扉2）
→ エリアC（追跡する敵・遠距離の敵・ボス）。ボスを倒すとクリア。エリア境界のチェックポイントで自動セーブ。

## 4. フォルダ構成

```
Assets/
  Scenes/Main.unity        ゲーム本体のシーン（全オブジェクトに GameAllInOne が付いている）
  Scripts/GameAllInOne.cs  ゲームのすべて（約 650 行）
  Materials/               床・壁・キャラの色
  Settings/                URP の設定
  TextMesh Pro/            UI 文字の必須リソース
```

## 5. 整理のヒント（授業で扱う順）

1. **`kind` ごとに別クラスへ分ける**（Player / Enemy / Bullet / Item / Door ... ）。`Update()` の中の `if (kind == "...")` が消える。
2. **敵の種類ごとの数値（HP・速さ・色…）を ScriptableObject に出す。** `switch (enemyType)` が消える。
3. **`public` にしている変数を `[SerializeField] private` に戻す。** 外から触っていい値だけプロパティで公開する。
4. **文字列のキー（`"HasSave"` など）やマジックナンバーを定数にまとめる。**
5. **Prefab 化**して、同じ敵・同じアイテムをシーンに何体も直置きしなくて済むようにする。
